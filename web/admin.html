关于 selfnas

当前版本 —

selfnas 是一个开箱即用的私有文件站，把这台电脑变成你自己的文件中心： 躺在床上用手机看电脑里的电影，把手机拍的照片和视频传回电脑做剪辑、修图， 随手翻看任意一个盘里的文件——数据全部留在自己手里，不经过任何第三方。

项目完全开源（MIT 协议），代码托管在 GitHub： github.com/sylvesterzhang/selfnas。 如果它对你有用，欢迎去点个 Star；遇到问题或有新想法，也欢迎去提 Issue。

selfnas 免费开源，禁止倒卖。任何人都不应该为这个软件本身付钱—— 如果你是花钱买到它的，请直接向卖家申请退款，并欢迎到 GitHub 提 Issue 告诉我们。

发布时会同时编译 Windows / Linux / macOS 三个平台，但只有 Windows 版经过实际测试。 Linux 和 macOS 的包是交叉编译出来的，大概率能用但不打包票——如果在这些平台上遇到问题， 请直接到 GitHub 提 Issue，看到就会跟进。
